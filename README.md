# 🎮 Feta Game

A modern **Telegram Web App** that brings multiple exciting mini-games into one seamless platform. Built with a fast, responsive interface and optimized for Telegram users, **Feta Game** delivers an engaging gaming experience directly inside Telegram without requiring any installation.

---

## 🚀 Features

- 🎯 Fully integrated Telegram Web App
- ⚡ Fast and responsive user interface
- 📱 Mobile-first design
- 🎮 Five exciting mini-games
- 🔐 Secure Telegram authentication
- 🌙 Modern and intuitive UI
- 💰 Interactive gameplay with real-time user interactions

---

# 🎲 Available Games

## 🃏 Card Draw
Test your luck by drawing cards. Pick the winning card and challenge your probability instincts.

### Features
- Random card generation
- Smooth card animations
- Instant results
- Engaging visual effects

---

## 🚀 JetX Pick
Predict the perfect moment before the multiplier flies away.

### Features
- Dynamic multiplier system
- Fast-paced gameplay
- High-risk, high-reward mechanics
- Smooth animations

---

## 🧠 Memory Flip
Challenge your memory by matching identical cards within the shortest time possible.

### Features
- Memory matching gameplay
- Multiple difficulty levels
- Score tracking
- Responsive game board

---

## 💣 Mines Duel
Avoid hidden mines while revealing safe tiles to maximize your reward.

### Features
- Random mine generation
- Strategic gameplay
- Risk management
- Instant game outcomes
